- **화면보다 긴 화면:** 굴린 만큼 그 화면 안에서만 내려가고, 화면 끝을 넘지 않아요. 끝에 닿은 뒤 새로 굴리면 다음 화면으로 넘어가요.
  - 트랙패드 관성(0.22초 안에 이어 오는 휠)은 넘김으로 세지 않아요.
  - 위로 갈 때는 앞 화면의 끝부분에 내려앉아요.
  - 넘치는 길이가 섹션 아래 여백(48px)보다 작으면, 잘리는 내용이 없으니 한 화면으로 봐요.
- 1440×900에서 휠을 흉내 내 확인한 결과:
  - 지원 찾기(958px), 계약 전 확인(951px), 시작하기(985px): 안에서 조금 내려간 뒤 다음 화면으로 넘어가요.

  - 문제(909px): 한 화면으로 넘어가요.
- **꺼지는 조건:** 폭 900px 이하, 높이 560px 미만, 메뉴가 열려 있을 때는 일반 스크롤이에요.
- **움직임 줄이기 설정**(prefers-reduced-motion)이면 움직이지 않고 바로 이동해요.
- **시작하기의 단지 가로 목록**(`.plans__track`)은 옆으로 미는 휠과 터치를 막지 않아요.

### 2. 오른쪽 섹션 점 · 맨 위로 · 어두운 화면 메뉴
- `#fpDots`: 화면 이름은 각 `.hs`의 `data-hs` 값을 쓰고(처음 / 문제 / 지원 찾기 / 지도·집 보기 / 계약 전 확인 / 시작하기 / 끝), 마우스를 올리면 이름이 나와요.
- `#toTop`: 홈 맨 끝에 닿으면 나타나요.
- 어두운 화면(히어로·푸터)에서는 점과 위 막대 글자가 밝아져요(`.nav.is-dark`). 히어로 맨 위에서는 원래의 투명 막대(`is-clear`)가 먼저예요.
- PC 푸터 아래 여백을 112px로 늘렸어요. 맨 위로 단추가 저작권 줄을 가려서예요.

### 3. 가구 전·후 슬라이더
- 화면에 들어올 때마다 한 번 왔다갔다 해요(놓은 후 → 놓기 전 → 가운데).
- 돌아가는 중에 화면을 벗어나면 멈추고 처음 자리로 돌아가요.

### 4. 지도 카메라 (`app_bb.js` MapView)
- **선택 전(overview):** 판정 단지 8곳과 미분양 점 60곳이 왼쪽 패널·위 막대를 피해 모두 들어오게 줌아웃해요.
  - PC 1440×900 배율은 26.8이에요. 예전 처음 배율 26과 거의 같아서, 단지가 늘어도 더 멀어지지 않았어요.
- **휴대폰 overview:** 미분양 점까지 넣으면 배율이 9.9로 너무 멀어져요(예전 17). 그래서 휴대폰은 판정 단지만 맞춰요(13.7). 미분양 점은 지도에 그대로 있고 끌어서 볼 수 있어요.
- **단지 선택:** 카드를 먼저 연 뒤 카드 자리를 재고, `placeAt`으로 카드에 가리지 않는 영역 가운데로 줌인해요(`flyTo`, 배율 36~44).
  - PC에서는 카드 왼쪽 지도 가운데로 가요(확인: 이름표 x 438~583, 카드는 x 1022부터).
  - 휴대폰에서는 건물이 시트 위에 서요.
- **카드 X:** 다시 overview로 줌아웃해요. 미분양 점 카드를 닫을 때도 같아요.

### 5. 선택 표시
- 고른 단지의 벽·띠·이름표를 구별 색(`GU_PAL`)으로 칠해요. 카드가 열려 있는 동안 다른 단지 7곳, 다른 이름표, 미분양 점 60곳은 숨겨요.

  - 대구 9개 구·군 모두에 색을 줬어요(달성군·군위군은 새로 더함).
