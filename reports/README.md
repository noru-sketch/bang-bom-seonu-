# reports — 작업 보고서

큰 작업을 하나 끝낼 때마다 이 폴더에 `<이름>.md` 파일로 보고서를 써요. 맨 위에 `---`로 감싼 머리말(`title`, `subtitle`, `date`)을 적으면 PDF 첫머리에 제목 칸이 생겨요. 본문은 이번에 한 일, 실제로 실행한 확인 명령과 결과를 적고, 마지막은 꼭 **실행 방법**과 **다음 할 일 3개**로 끝내요. 표, 목록, 코드 칸, 인용문(`>`로 시작하면 안내 상자가 돼요), 그림(보고서 파일 기준의 상대 경로)을 쓸 수 있어요. 사람 이름, 내 PC 경로, API 키는 적지 않아요. 예시는 `sample/sample.md`에 있어요.

PDF는 프로젝트 폴더에서 `npm run report -- reports/<이름>.md`로 만들어요(여러 파일을 한 번에 적어도 돼요). 결과는 `reports/pdf/<이름>.pdf`에 생기고, 중간 결과인 `.html`은 같은 폴더에 남지만 Git에는 올라가지 않아요. 이 PC에 깔린 Edge나 Chrome을 화면 없이 띄워 A4로 인쇄하는 방식이라 인터넷이 없어도 돼요. 브라우저를 찾지 못하면 `BROWSER_PATH` 환경변수에 브라우저 실행 파일 경로를 넣고 다시 실행해요.
