방봄 GitHub 도우미 — 명령어 몰라도 됩니다
=============================================

[처음 한 번만]
1. GitHub 가입 → PM(선우)에게 GitHub 아이디 알려주기
2. 메일/GitHub 알림으로 온 초대(Invitation)를 "Accept" 누르기
3. 이 zip을 원하는 곳(예: 바탕화면)에 압축 풀기
4. 0_처음_받기.cmd 더블클릭 → PM이 보낸 저장소 주소 붙여넣기
   - GitHub 로그인 창이 뜨면 로그인
   - 이름/이메일을 물어보면 입력 (한 번만)
5. 생긴 bangbom 폴더가 앞으로의 작업 폴더예요.

[매번 작업할 때] (bangbom 폴더 안에서)
  작업 시작 전  →  받기_pull.cmd     (팀원 수정 받기)
  작업 끝난 뒤  →  올리기_push.cmd   (한 줄 설명 쓰고 Enter)
  화면 확인     →  시연하기.cmd

[규칙]
- 작업 전에 꼭 "받기"부터. 충돌이 거의 안 생겨요.
- index.html은 직접 고치지 말고 src 폴더를 고치세요 (올리기 때 자동으로 다시 만들어요).
- .env(API 키)는 절대 GitHub에 올라가지 않게 막혀 있어요. 키는 팀 채팅으로만.
- "충돌"이라는 말이 나오면 혼자 고치지 말고 화면 캡처해서 PM에게.

[Windows가 "PC 보호" 경고를 띄우면]
  "추가 정보" → "실행" 누르면 됩니다.
