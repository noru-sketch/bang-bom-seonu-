# CONSULT_SPEC.md · 판정 결과 패널과 24시간 상담 (v3 신규)

> 수정 범위: 백엔드 `backend/consult.py`, `backend/data/policy_docs/`, 프론트 `frontend/src/consult/`
> API 형식은 API_SPEC 7장.

## 1. 원칙 (발표에서도 이대로 말한다)
1. **판정은 규칙이, 설명은 AI가.** `rules.py`가 낸 판정(eligible / needs_check / ineligible)과 숫자만 사실로 쓴다. LLM은 판정을 바꾸지 않고 새 숫자를 계산하지 않는다.
2. **모르면 모른다고.** 공고 요약(policy_docs)에 없는 내용은 "공고에서 확인이 필요해요" + 담당 기관 링크.
3. **단정 금지.** "대출 가능", "선정됩니다", "승인돼요" 금지. "입력하신 조건 기준으로 요건 충족이에요. 최종 결정은 {기관}이 해요."
4. **링크는 서버가 붙인다.** LLM이 쓴 URL은 지우고, rules.json·policy_docs의 공식 링크만 `links`로 보낸다.
5. **개인정보를 받지 않는다.** 주민번호·계좌·서류 사진을 요구하지 않고, 사용자가 쓰면 "그런 정보는 입력하지 마세요"라고 안내. 대화는 서버에 저장하지 않는다.
6. **마지막은 행동으로.** 답변 끝은 다음 할 일 한 가지 + 링크 (신청 페이지, 상담 전화, 은행 사전 상담).

## 2. 화면
### S1-R 판정 결과 패널 (S1 제출 직후, 지도 왼쪽에 고정)
```
김지훈 님 조건으로 본 결과                     기준일 2026-11-26
대출
 ● 청년전용 버팀목 전세자금대출   요건 충족   추정 연소득 기준 이하   [출처]
 ◐ 시중은행 전세대출              확인 필요   은행 심사로 결정
지원
 ◐ 대구 청년 이자지원             확인 필요   배점 선정 결과 확인     [출처]
 ○ 청년월세 특별지원              미충족      추정 소득인정액 초과    [출처]
───────────────────────────────
지도에서 ● 3곳 · ◐ 2곳 · ○ 3곳
[지도에서 보기]  [상담 이어가기 →]
```
- 각 줄을 누르면 이유 전체와 "확인하려면: ~" 한 줄, 출처 링크가 펼쳐진다.
- [상담 이어가기]는 상담 창을 열고 첫 메시지를 자동으로 보낸다: "내 판정 결과를 쉽게 설명해 줘".

### S6 상담 창
- 오른쪽 아래 둥근 버튼 "24시간 상담" → 오른쪽 서랍(폭 380px, 모바일은 전체 화면).
- 둘러보기 모드에서도 열린다 (profile 없이 일반 질문만, 판정 질문이면 "정보를 입력하면 정확히 알려드려요" + [정보 입력] 버튼).
- 단지 카드에서 열면 `complex_id`가 같이 간다.
- 상단 고정 문구: "AI 안내 · 참고용이며 최종 판정은 각 기관이 합니다"
- 빠른 질문 칩 (템플릿 모드에서도 동작):
  1. 내 판정 결과 쉽게 설명해 줘
  2. 확인 필요는 어떻게 확인해요?
  3. 신청은 어디서, 뭐가 필요해요?
  4. 이 단지 월 부담은 어떻게 계산했어요?
  5. 계약 전에 꼭 확인할 것은?

## 3. 정책 공고 요약 (policy_docs) — PM 작성
은행·공공기관 공고를 읽고 지원 하나당 파일 하나. LLM은 이 파일과 판정 결과만 본다.
`backend/data/policy_docs/daegu_interest.md`
```markdown
---
id: daegu_interest
name: 대구 청년 임차보증금 대출이자 지원
agency: 대구시
announcement: 2026년 하반기 모집 공고
checked_at: 2026-11-26
apply_url: https://...
info_url: https://...
phone: "{담당 부서 전화}"
---
## 대상
- 만 19~39세, 무주택, 대구 거주 또는 전입 예정
## 지원 내용
- (공고 문구를 쉬운 말로 요약)
## 제외
- 주택도시기금 전세대출(버팀목 등) 이용자
## 신청 방법과 서류
- ...
## 선정 방식
- 배점제 (일반청년), 우선순위 ...
## 자주 묻는 질문
- Q. ... A. ...
```
- 시연에 쓰는 지원: `youth_beotimok`, `market_jeonse_loan`(일반 안내), `daegu_interest`, `youth_monthly_rent`, `lh_dundeun`(공급 안내), `cr_reits`(공급 안내)
- 공고 문장을 길게 복사하지 말고 요약한다. 숫자는 rules.json과 같아야 한다.

## 4. 처리 순서 (consult.py)
1. `profile`이 있으면 `rules.py`로 판정 결과를 다시 계산한다 (프론트가 보낸 판정은 믿지 않는다).
2. 질문에서 관련 지원 id를 찾는다: 이름·별칭 키워드 매칭(예: "버팀목", "이자지원", "월세") + `complex_id`의 적용 지원.
3. 관련 policy_docs 최대 3개 + 판정 결과 JSON + (단지가 있으면) breakdown을 프롬프트에 넣는다.
4. LLM 호출 (타임아웃 8초, 최대 출력 400토큰, temperature 0.3).
5. 후처리: URL 삭제 → 금지어 검사("가능합니다", "승인", "확정", "보장") → 걸리면 해당 문장을 "요건 충족 기준이에요. 최종 결정은 기관이 해요"로 교체.
6. `links`: 관련 지원의 `apply_url`·`info_url`, 단지가 있으면 `apply_links`.
7. 실패하면 템플릿(5장)으로 같은 형식 응답, `mode: "template"`.

## 5. 템플릿 답변 (LLM 없이도 시연 가능하게)
- "판정 설명": profile_result를 줄마다 "{이름}: {상태 한국어}. {reason}" 로 이어 붙이고 끝에 "확인 필요 항목은 '확인 필요는 어떻게 확인해요?'를 눌러 보세요."
- "확인 방법": needs_check 항목마다 "{이름}: {always_needs_check 또는 reason} → {agency}에 문의 ({phone}) / {info_url}"
- "신청": 관련 policy_docs의 `## 신청 방법과 서류` 섹션 그대로
- "월 부담": breakdown을 "관리비 15만 + 대출이자 29.2만(1억 4,000만 원 × 2.5% ÷ 12) = 월 44.2만 원"
- "계약 전": 고정 체크리스트 2개 + "등기부등본으로 소유자·근저당 확인", "전세보증보험 가입 가능 여부 확인"
- 그 외 질문: "그 질문은 아직 답을 준비하지 못했어요. {관련 기관} 상담으로 연결해 드릴게요." + 링크

## 6. 시스템 프롬프트 (그대로 사용)
```
너는 대구로 이사 오는 사람을 돕는 주거 지원 안내원이다.
반드시 지킬 것:
- [판정 결과]에 있는 상태와 숫자만 사실로 말한다. 판정을 바꾸거나 새 금액·금리를 계산하지 않는다.
- 상태는 "요건 충족", "확인 필요", "미충족"으로만 말한다. "가능", "승인", "확정", "보장"이라고 말하지 않는다.
- [공고 요약]에 없는 내용은 추측하지 말고 "공고에서 확인이 필요해요"라고 말하고 담당 기관을 알려 준다.
- URL을 쓰지 않는다. 링크는 화면에 따로 나온다.
- 주민번호, 계좌번호, 서류 사진을 요청하지 않는다.
- 한국어 존댓말, 5문장 이내, 쉬운 말. 마지막 문장은 사용자가 바로 할 수 있는 다음 행동 하나.
[판정 결과]
{profile_result JSON}
[단지 계산]
{breakdown JSON 또는 "없음"}
[공고 요약]
{policy_docs 최대 3개}
```

## 7. 발표에서 말할 것
- "24시간 상담"의 근거: 공고는 업무시간에만 문의할 수 있고, 청년은 퇴근 후에 집을 찾는다.
- 신뢰 장치: 규칙 판정과 AI 설명의 분리, 출처·기준일, 링크는 공식 주소만, 대화 미저장.
- 시연은 LLM이 안 될 때를 대비해 템플릿 모드로도 리허설한다.

## 8. 완료 체크
- [ ] 페르소나로 "내 판정 결과 쉽게 설명해 줘" → 4개 항목 상태가 패널과 같다
- [ ] "버팀목이랑 대구 이자지원 같이 받을 수 있어요?" → 중복 불가라고 답한다
- [ ] "대출 돼요?" → "가능"이라는 말 없이 요건 충족 + 은행 확인 안내
- [ ] LLM 키를 빼도 빠른 질문 5개가 모두 답한다
- [ ] 답변 아래 링크가 공식 주소만 나온다
