# 시연 가이드 (2분 버전)

## 켜기
1. `bangbom` 폴더의 **시연하기.cmd** 더블클릭 → 검은 창이 뜨고 2초 뒤 브라우저가 열림 (검은 창을 닫으면 꺼짐)
2. 상담 AI: 처음 한 번 실행하면 `.env`가 생긴다 → 창을 닫고 `.env`를 메모장으로 열어 `BAZE_API_KEY=` 뒤에 키를 붙여 넣고 저장 → 다시 시연하기.cmd (키는 자동 암호화되고 원래 칸은 비워짐)
3. 인터넷 연결 필요 (3D 지도 라이브러리를 인터넷에서 불러옴)

## 누를 순서
| # | 누를 것 | 보여줄 것 · 말할 것 |
|---|---|---|
| 1 | 홈에서 **그냥 둘러보기** | 잿빛 도시 위에 미분양 단지만 솟아 있다. "대구 준공 후 미분양 3,077세대, 정보 없이도 누구나 둘러볼 수 있어요" |
| 2 | 위쪽 **조건 바꾸기**(또는 홈의 **기본정보 입력하고 더 알아보기**) | 입력 화면 |
| 3 | **예시 페르소나 넣기 · 김지훈(27)** → **판정 결과 보기** | 판정 패널: 버팀목 요건 충족, 대구 이자지원 확인 필요, 청년월세 미충족. "대출 가능이라고 말하지 않고 세 단계로만 말해요" |
| 4 | 지도 | ● 3곳 불이 켜지고 ◐ 2곳 깜빡, ○ 3곳은 어둡지만 숨기지 않음 |
| 5 | **상인푸르지오 센터파크** 클릭 | 줌인 → 지하철·병원 선 → 카드 "지원 반영 월 OO만 원 / 하나도 못 받으면 OO만 원". **계산 내역**, **계약 전 체크리스트** 펼치기 |
| 6 | **이 단지 상담하기** → "버팀목이랑 대구 이자지원 같이 받을 수 있어요?" | 중복 불가라고 답하고 신청 링크로 끝남. "판정은 규칙이 하고 AI는 설명만 해요" |
| 7 | 카드의 **집 보기** | 평면도 → **조감도** → **방 안** 전환 |
| 8 | 배치 탭 **기본형** → 가구 하나 끌어서 옮기기 | |
| 9 | **예산 추천** 탭 → 300만 원 → **맞춰 추천** → **구매 목록** | 합계와 링크. "가 보지 않고 입주 결정까지" |

## 실패 대비
- 상담 창 제목 옆이 "기본 안내"면 AI가 꺼진 상태(키 없음·인터넷 문제). 정해진 답변으로 그대로 진행해도 된다.
- 지도가 하얗게 안 나오면 인터넷 연결 확인 후 새로고침.
- 주소 끝을 `#map`, `#house`로 바꾸면 그 화면으로 바로 이동.
- 마감 4시간 전에 이 순서대로 화면 녹화를 한 번 해 둔다.
