[절대 규칙]
- .env 를 열거나 출력하지 않는다. API 키·인증키를 어떤 파일에도 쓰지 않는다.
- index.html 을 직접 고치지 않는다. src/ 를 고치고 `python src/shell/build.py` 로 만든다.
- 화면 문구에 "대출 가능", "확정", "안전한 집", "법인·리츠라 안전" 을 쓰지 않는다. 판정은 요건 충족 / 확인 필요 / 미충족 세 가지뿐.
- 네이버 지도 캡처·이미지는 쓰지 않는다.
- git commit / push 는 하지 않는다 (PM이 올리기_push.cmd 로 직접 올린다).
- 코드가 여러 사람 버전을 합친 상태일 수 있다. 각 항목을 고치기 전에 **이미 반영돼 있는지 먼저 확인**하고, 맞게 돼 있으면 건드리지 않는다. 구조가 이 지시서와 다르면 지금 코드 구조에 맞춰 같은 결과가 나오게 한다.
- 시작할 때 `git status` 와 현재 브랜치를 한 줄로 보고한다.

B. 매매 참고 계산 (단지에 sale_price 가 있을 때만)
----------------------------------------------------------------
분양가·할인가 출처가 있는 단지에만 sale_price(만 원)·sale_source 를 넣고, 상세 카드에 접히는 "매매로 보면" 칸을 만든다. 출처 없는 단지는 칸 자체를 숨긴다.
B1. 디딤돌대출
  - 무주택 세대주, 연소득 6,000만(생애최초 7,000만, 신혼 8,500만), 평가액 5억(신혼 6억)·85㎡ 이하
  - 미혼 단독세대주: 만 30세 이상은 60㎡·3억 이하만 → 초과면 미충족 / 만 30세 미만은 "확인 필요"(부양 요건)
  - 금리 = 기본(표기 연 2.85~4.15%, 계산은 상단) − 지방 준공 후 미분양 0.2 − 생애최초 0.2 (우대 합계 ≤ 0.5), 최저 1.5%
  - 한도 2억(생애최초 2.4억), LTV 70%(생애최초 80%)
  - 카드 한 줄: "지방 준공 후 미분양이라 금리 0.2%p 우대 대상이에요"
B2. 보금자리론: 6억 이하, 연 5.0~5.3%(2026-07 공시, 기준월 표시), 상태 항상 "확인 필요"
B3. 취득세
  - 기본 1.1%(6억 이하, 지방교육세 포함)로 계산
  - 대구 준공 후 미분양 감면: 85㎡·취득가액 6억 이하 + 분양사에게서 최초 취득일 때 감면액 = min(취득세×50%, 150만), "한도 적용 여부 확인 필요" 표시
  - 생애최초 감면(최대 200만)과 중복 여부 미확정 → 둘 중 큰 쪽 하나만 적용
B4. 월 부담 비교 문구: "전세로 살 때 월 ○○만 / 사서 살 때 월 ○○만(원리금+관리비)". 자기자금 부족이면 부족액을 크게 보여 준다.
