# 작업지시서 3 · 실부담 계산 검증 (전세·월세·매매)

**목표**: 같은 사람이 같은 단지에 **전세·월세·매매**로 들어갈 때 한 달에 각각 얼마인지 계산하고, 앱 결과를 검증한다. 그리고 **"일반 매물보다 한 달에 얼마 덜 낸다"** 비교를 만든다. 이게 다른 앱에 없는 숫자다.

## 계산식
**전세 (지금 앱)**
- 필요 대출 = 보증금 − 모은 돈
- 월 이자 = 필요 대출 × 금리 ÷ 12  (버팀목 2.5%, 시중 4.5%, 대구 이자지원은 금리에서 차감 — 2번 조사로 확정)
- 월 실부담 = 관리비 + 월 이자 + 보증보험료÷12

**월세·반전세 (새로 추가)**
- 월 실부담 = 월세 + 관리비 + (보증금 대출 이자) − 월세지원 − (월세 세액공제 ÷ 12, 참고)

**매매 (새로 추가)**
- 필요 대출 = 매매가(할인 후) − 모은 돈 → LTV 한도 안인지 확인
- 월 원리금 = 대출 × r ÷ (1 − (1 + r)^−n)   (r = 연금리 ÷ 12, n = 상환 개월 수, 원리금균등)
- 월 실부담 = 월 원리금 + 관리비 + 재산세 ÷ 12
- 첫 해 한 번 드는 돈: 취득세(감면 반영), 중개수수료, 이사비 → 따로 표시
- 참고: 원리금 중 원금은 "내 집에 쌓이는 돈"이라 순수 비용이 아님 → **"월 지출"과 "그중 이자·세금(사라지는 돈)"** 을 같이 표시

## 할 일
1. **계산식 점검**: 빠진 비용, 잘못된 가정 표시 (보증보험료, 중개수수료, LTV·DSR, 중복 불가 조합 — 2번 결과와 맞추기)
2. **손 계산 테스트**: 4명 × 단지 3곳 × 가능한 거래유형
   - A 김지훈: 27세, 월 실수령 250만, 모은 돈 1,000만, 무주택, 대구 전입 예정, 월 예산 60만
   - B: 33세, 월 실수령 320만, 모은 돈 4,000만, 월 예산 80만
   - C: 38세(대구 이자지원 O, 버팀목 X), 월 실수령 280만, 모은 돈 2,000만, 월 예산 70만
   - D 공공기관 이전 직원 가족: 36세, 부부 합산 연소득 7,000만, 모은 돈 1억 5,000만, 생애최초, 월 예산 150만 → **매매 중심**
3. **일반 매물과 비교**: 1번 조사의 주변 시세로 같은 사람이 일반 매물(같은 유형)에 들어갈 때 월 부담 계산
   - 예: "방봄 단지 전세 월 44만 / 같은 동 일반 전세 월 61만 → 월 17만 원, 2년 408만 원 절약"
   - 예: "할인분양 매매 월 132만 / 같은 동 일반 매매 월 151만 → 월 19만 원 절약 + 취득세 감면 ○○만 원"

## 체크

- [ ] 절약액은 "가정" 조건(금리, 시세 출처)과 함께 표시
