# 온라인 모델하우스 · 서비스 기획안 (v3)
2026 안산대 해커톤 · 주제: 지역사회 문제 해결 (대구 미분양 · 정착)
11/26 16시 개정 · 이전 판(v2)을 대체한다

## 1. 한 줄 소개
대구로 오는 사람이 **가 보지 않고도 집을 고를 수 있는 온라인 모델하우스**. 2.5D 지도에서 미분양 아파트만 밝게 떠오르고, 내 조건을 넣으면 들어갈 수 있는 단지에 불이 켜진다. 단지를 고르면 평면도와 3D 조감도로 집 안을 둘러보고 가구를 놓아 보며, 대출·지원은 24시간 상담으로 신청 단계까지 안내받는다.

## 2. 문제 정의
**빈집은 있다.** 2026년 9월 말 대구 미분양 3,889호 중 준공 후 미분양이 3,077호(79.1%)로 전국 시·도 중 가장 많다. 새 공급은 거의 멈췄다(9월 인허가 12호). *(국토부 9월 주택통계)*

**풀리면 찬다.** 분양 계약이 한 건도 없던 달서구 상인푸르지오 센터파크(990가구)는 CR리츠 편입 후 전세로 나오자 2차 계약 때 최대 43시간 대기 줄이 생겼다. *(뉴시스·뉴스1 2026.9)*

**그런데 사람은 떠나고, 지원은 안 쓰인다.** 최근 5년 대구 청년 35,821명이 순유출됐다. 청년이 가장 원하는 정책은 주거(45.7%)인데, 2026년 대구 청년 주거지원 예산 집행률은 33.6%(10월 기준)다. *(대구시 시의회 제출 자료, 국무조정실 청년의 삶 실태조사)*

**앞으로 대구로 올 사람은 더 늘어난다.** 대구시는 2차 공공기관 이전 유치를 위해 43개 정착 지원책을 내놨다. 주거 분야에는 이전 기관 직원·가족 대상 취득세 감면, 전월세 대출이자 지원, 중개수수료 지원 등이 들어 있다. *(경북매일 2026.10.15)* → 지원은 늘어나는데, 오는 사람이 집과 지원을 한 번에 보는 곳은 없다.

**핵심 원인: 정보 격차와 거리.**
- 자격 기준은 해마다 바뀌고(대구 이자지원 연령 2025년 만 19~34세 → 2026년 만 19~39세), 국가·시 사업이 따로 있으며 서로 중복이 안 되는 조건도 있다. 혼자 계산하기 어렵다.
- 다른 지역에서 오는 사람은 주말에만 집을 볼 수 있다. 모델하우스를 보러 대구까지 몇 번씩 오기 어렵다.

> 표현 원칙: 3,077호는 **문제의 규모**이지 지금 임대 가능한 물량이 아니다. "정보 부족이 미분양의 원인"이라고 단정하지 않고, "빈집과 수요를 잇는 통로가 없다"로 말한다. 기사(공공기관 이전)는 문제 인식 근거로만 쓰고, "대구시가 이전 직원을 미분양과 연결한다"고 말하지 않는다.

## 3. 대상 사용자
| 구분 | 페르소나 | 시연 |
|---|---|---|
| 1차 | 김지훈(27): 서울 거주, 대구 기업 합격, 월 실수령 250만 원, 모은 돈 1,000만 원, 월 예산 60만 원. 지원 자격을 모르고 대출 거절이 걱정됨 | 시연 주인공 |
| 확장 | 이전 공공기관 직원(가족 동반): 취득세 감면·이자지원 대상, 매수와 전세를 함께 고민 | 발표 슬라이드만 |

## 4. 서비스 흐름
| 단계 | 화면 | 사용자가 얻는 것 |
|---|---|---|
| 0 | **시작 화면**: [그냥 둘러보기] / [기본정보 입력하고 더 알아보기] | 원하는 만큼만 정보를 준다 |
| 1 | **정보 입력** (더 알아보기만): 나이, 월 소득, 모은 돈, 무주택, 부모님과 따로 사는지, 대구 거주·전입 예정, 월 예산, 중요한 시설(선택) | 30초 입력 |
| 2 | **판정 결과 패널**: 대출·지원별 "요건 충족 / 확인 필요 / 미충족"과 이유 → [상담 이어가기] | 내가 받을 수 있는 지원을 한 번에 |
| 3 | **2.5D 미분양 지도**: 실제 배치를 본뜬 잿빛 도시 위에 미분양 단지만 색과 빛으로 솟는다. 더 알아보기 모드에서는 조건에 맞는 단지가 빛나고(●), 확인이 필요한 단지는 깜빡이며(◐), 안 맞는 단지는 어둡게(○) 보인다. **숨기지 않는다** | 들어갈 수 있는 집이 한눈에 |
| 4 | **단지에 마우스 올리기/터치**: 단지를 중심으로 지하철역·병원·쇼핑·영화관 등으로 선이 뻗고 "도보 6분" 표시 + 생활 편의 평가 | 가 보지 않고 입지 판단 |
| 5 | **단지 카드**: 둘러보기는 기본 정보, 더 알아보기는 **지원 반영 후 월 부담**과 범위, 적용 지원, 체크리스트, 신청 링크 | 계약 전에 숫자로 확인 |
| 6 | **집 보기 (핵심)**: 평면도 / 3D 조감도 / 방 안 시점을 카메라 이동으로 전환, 가구 끌어다 놓기, 추천 배치, 예산 맞춤 가구 추천, 구매 링크 | 입주 후 생활까지 미리 보고 결정 |
| 7 | **24시간 상담**: 판정 결과를 바탕으로 질문에 답하고, 마지막에 신청·상담 링크로 연결 | 혼자 공고문을 읽지 않아도 된다 |

## 5. 판정과 상담: 믿을 수 있게 만드는 장치
- **판정은 규칙이, 설명은 AI가 한다.** 은행·공공기관 공고를 PM이 검토해 규칙 파일(`rules.json`)로 만들고, 파이썬 스크립트가 요건을 판정한다. 소형 LLM은 이 판정 결과와 공고 요약만 보고 쉬운 말로 설명한다. LLM은 판정을 바꾸거나 새 숫자를 만들지 않는다.
- 판정은 세 단계로만 말한다: **요건 충족 / 확인 필요 / 미충족**. "대출 가능", "입주 확정"이라고 하지 않는다.
- 월 실수령만으로 판단할 수 없는 기준(연소득, 소득인정액)은 억지로 판정하지 않고 "확인 필요"로 둔다.
- 중복이 안 되는 지원(예: 대구 이자지원은 주택도시기금 전세대출 이용자 제외)은 같이 더하지 않는다.
- 실부담(월) = 월세 + 관리비 + 보증금 대출이자 − 월세지원 − 이자지원. "지원 모두 받으면 ~ / 하나도 못 받으면 ~" 범위를 같이 보여 준다.
- 모든 지원에 **출처 링크와 기준일**을 붙이고, 상담 마지막 답변은 공식 신청 링크로 끝난다(링크는 서버가 붙이고 AI가 지어내지 않는다).
- 체크리스트 맨 위: "계약금 전 은행 사전 상담", "대출 불가 시 계약 해제 특약 확인". 서울시 전월세종합지원센터도 이 특약을 권장한다.
- 화면 하단 고정: "샘플 데이터 · 참고용, 최종 판정과 승인은 각 기관"

## 6. 지도: 미분양에만 시선이 가게
- 네이버지도 화면을 **참고만** 해서 미분양 지역구의 건물·큰길 위치를 단순한 블록으로 본뜬다. 상세 도로, 상호, 지명은 그리지 않는다. 지도 화면 자체를 복사하거나 배포하지 않는다.
- 도시 전체는 잿빛, 주요 시설은 연한 색의 작은 아이콘, **미분양 단지만 크고 밝은 색에 빛난다.**
- 인프라 선은 평소에 숨겨 두고, 단지에 마우스를 올리거나 터치하면 그 단지에서 뻗어 나온다.
- 생활 편의 평가는 "좋은 동네 / 나쁜 동네"가 아니라 **시설까지의 거리**로 보여 준다(지하철 도보 6분 ✓, 종합병원 차로 12분 등). 사용자가 고른 중요한 시설에 가중치를 준다.

| AI 인테리어 앱 | 꾸미기 중심 | 실제 평형·예산 기준으로 입주를 결정하는 도구 |

## 8. 기대효과
| 수혜자 | 효과 | 측정 지표 (실증 시) |
|---|---|---|
| 청년·이주자 | 집 찾기·자격 확인 시간 단축, 대출 거절 손실 예방 | 조건 입력부터 후보 비교까지 걸린 시간 (시연 지표) |
| 공급자(CR리츠·LH·건설사) | 원거리 수요자에게 노출, 공실 기간 단축 | 단지별 상세 조회 → 문의 전환율 |
| 대구시 | 청년 주거지원 집행률(33.6%) 개선, 정착 인구 유입 | 상담 → 신청 링크 클릭 건수 |

숫자 목표는 가정치로만 말하고, 3,077호에 비율을 곱한 "해소 가구 수"는 쓰지 않는다.

## 9. 지속 운영 방안
- 대구시·공공기관 위탁 운영(청년 정착·공공기관 이전 지원 사업과 연계), 수요 데이터(어느 조건의 사람이 어떤 단지를 보는지) 대시보드 제공.
- 공급자 제휴로 단지·평면 데이터를 받는다. **불빛과 순서는 오직 사용자 조건과 실부담으로 정하고, 제휴·광고는 별도 표시한다.**
- 가구 구매 링크 제휴 수수료로 운영비를 보탠다(제휴 링크임을 표시).
- 정책 규칙은 공고 버전·기준일로 관리하고, 공고가 바뀌면 규칙 파일만 고친다.

## 10. 리스크와 대응
| 리스크 | 대응 |
|---|---|
| 단지별 실시간 데이터 비공개 | 공개 보도 단지 + 샘플("(샘플)" 표시)로 시연, 실서비스는 공급자 제휴 |
| 판정 오류 | 3단계 표시, 애매하면 "확인 필요", 출처·기준일 표시, "최종 판정은 기관" 고지 |
| AI 상담 오답 | 판정은 규칙이 하고 AI는 설명만, 링크는 서버가 붙임, 답 못 하면 기관 연결 |
| 평면도 원본 사용 | 공고 평면도를 참고해 단순화한 평면을 직접 그림, 원본 이미지 미사용 |
| 지도 저작권 | 네이버지도는 위치 참고만, 화면 캡처는 저장소·발표에 넣지 않음 |
| 3D가 꾸미기로 보일 위험 | "가 보지 않고 결정한다"는 흐름 안에 배치, 실제 평형·예산과 연결 |

## 11. 향후 확장
실시간 미분양·임대 공고 연동, 은행 대출 사전심사 연동, 공공기관 이전 직원용 매수 판정(취득세 감면 반영), 평면도 자동 3D 생성, 신혼부부로 대상 확대.
