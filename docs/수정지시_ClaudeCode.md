- README의 "전국 바이브톤 경진대회"를 "2026 안산대학교 해커톤"으로, 팀원을 4명(선우·혜원·경동휘·이준석)으로 고쳐. 역할을 모르는 사람은 이름만.

## 2. 지도: 미분양만 확실히 보이게 + 클릭하면 줌인
```
작업 2를 해줘. (src/shell/app_bb.js 지도 부분)
- 미분양 단지 동 높이를 지금의 약 2.5배로, 바닥도 조금 키워서 주변 건물보다 확실히 크게. 일반 건물(작은 큐브)은 개수를 절반으로 줄이고 높이를 낮추고 색을 더 연한 회색으로. 화면이 지저분해 보이지 않게.
- ● 요건 충족 / ◐ 확인 필요 / ○ 미충족 차이를 멀리서도 보이게: 충족은 창 발광을 강하게 + 바닥 링, 확인 필요는 천천히 깜빡, 미충족은 채도를 낮추되 숨기지 않기.
- 클릭 판정을 넓혀: 단지마다 보이지 않는 큰 박스(동 묶음 전체를 덮는 크기)를 클릭 대상으로 써서 한 번에 잡히게.
- 마우스를 올리는 것만으로는 라벨·선이 나오지 않게 해 (커서 모양과 살짝 떠오르는 효과만).
- 클릭하면 카메라가 그 단지로 0.6초 줌인하고, 그다음에 시설 선과 라벨이 나타나게. 라벨은 카테고리마다 1개, 서로 겹치면 위아래로 밀어서 겹치지 않게. 카드를 닫으면 원래 줌으로 돌아가게.
빌드 후 단지 3개를 차례로 클릭해 겹침이 없는지 확인하고 멈춰.
```

## 4. 방 안 시점 고치기
```
작업 4: 집 보기의 "방 안" 시점을 고쳐줘.
- 지금은 카메라가 벽·가구에 붙어서 흰 면만 보여. 고른 방의 중앙, 눈높이 1.6m에서 방 전체가 보이게 (FOV 70 정도, near 0.05). 방 버튼(방2, 주방, 방3, 거실, 안방)을 누르면 그 방 중앙으로 0.8초 이동.
- 방 안 시점일 때 오른쪽 패널은 접히게 하고 "가구 패널 열기" 버튼으로 다시 열게.
- 조감도에서 "기본형" 추천 배치를 눌렀을 때 가구가 실제로 방에 놓이는지 확인하고, 안 놓이면 고쳐.
- 조감도의 방 이름표가 겹치는 곳(방2/드레스룸)은 위치를 조정.
빌드 후 방 안 시점에서 거실·안방이 어떻게 보이는지 말로 설명하고 멈춰.
```
