# S4_ROOM_UPGRADE.md · S4 3D 가구 배치 고도화 지시서 (방꾸미 2.0 + 방봄 결합)

> 이 문서는 `PROJECT.md`의 **S4(3D 가구 배치)** 및 **S5(구매 목록)**을 단순 꾸미기 데모가 아니라 **"실제 미분양 평형 입주 판단 도구"**로 고도화하기 위한 추가 명세입니다.
> 3D 좌표 규격(`1 = 1m`, `+Y Up`, 바닥 중앙 원점, `room_59a/84a/one.glb`)은 `MODEL_SPEC.md` B장을 그대로 따릅니다.
> 수정 범위: `frontend/src/room/` (또는 S4 전용 폴더) 및 `backend/`의 방 배치 관련 모듈.

## 1. S3(단지 상세) → S4(3D 가구 배치) 자연스러운 연결
- S3 단지 상세의 **[이 집에 가구 놓아보기]** 버튼을 누르면 해당 단지의 `room_id`(`room_59a`, `room_84a`, `room_one`)와 사용자의 **남은 가구 예산**이 S4로 자동 전달된다.
- **시연 시간 준수 (`기획안.md` 9장 대응):** S4가 "꾸미기 앱"으로 보이지 않도록 진입 즉시 해당 평형에 맞춘 추천 배치가 열리고, **30초 이내**에 "내 예산으로 이 평형에 가구가 다 들어가는지 + 3D로 걸어보면 어떤지 + 구매 총액"을 확인하고 S5로 넘어가게 설계한다.

## 2. 사용리뷰 기반 UX 개선 (S4 필수 반영)
기존 방꾸미 1.0 사용리뷰에서 확인된 핵심 불편사항을 S4 편집기에 반영한다.
1. **설명창 없는 즉시 진입:** S4 진입 시 안내 팝업 없이 바로 해당 평형 배치 화면을 띄운다.
2. **상단 고정 조작 바:** `[처음부터]` · `[실행취소(Ctrl+Z)]` · `[다시실행(Ctrl+Y)]` · `[2D/3D 전환]`을 상단에 고정한다.
3. **편의 단축키 (PC):** `Ctrl+C`(복사), `Ctrl+V`(붙여넣기), `Ctrl+Z/Y`(실행취소/다시실행), `R`(90° 회전), `Delete`(삭제), 방향키(5cm 미세이동).
4. **기존 배치 보존형 가구 추가:** 사용자가 가구를 하나 더 추가할 때 기존에 맞춰 둔 가구 위치를 날리지 않고 **빈 자리에만 추가**한다. 전체 재배치는 별도 `[전체 다시 추천]` 버튼으로 분리한다.
5. **보유 가구 예산 제외:** 가구마다 **`[이미 있어요]`** 스위치를 제공해 3D/2D 방에는 배치하되 S5 구매 합계에서는 제외한다.
6. **가격 직접 수정 + 공식 검색 링크:** S5 구매 목록의 모든 가격 칸은 클릭해 직접 수정 가능하며, 쇼핑몰(오늘의집·네이버쇼핑·쿠팡)은 무단 크롤링 대신 **공식 검색 링크**로 연결한다.

## 3. 점수제 폐지 → 3단계 전문가 배치 피드백 (유튜브 62편 원리 반영)
S4에서도 100점 점수제를 쓰지 않고, 건축인테리어 실무 원리에 따라 3단계로 피드백한다.
- **1단계 [확실한 문제 (빨간색 판정 — 코드 계산)]:**
  - 가구 겹침(`MODEL_SPEC.md` B장 DB 치수 직사각형 기준), 방 벽 이탈, 방문 열림 공간 침범, 서랍·옷장 앞 개폐 공간(50cm 참고값) 막힘, 의자 사용 공간(60cm 참고값) 침범.
- **2단계 [개선 제안 (주황색 팁 — 관습·참고값)]:**
  - **벽/인접 가구 밀착은 정상 허용:** 책상 옆 책장, 침대 옆 협탁처럼 딱 붙인 배치는 경고하지 않는다.
  - **데드스페이스 경고:** 오직 가구와 가구 사이의 어정쩡한 **5~50cm 틈**만 개선 제안으로 알린다.
  - 현관/방문에서 침대 직시선, 창문 바로 아래 침대 머리(외풍·결로 주의), 통로 60cm(참고값) 미만 구간.
- **3단계 [취향별 테마 배치안 (최대 3~5안)]:**
  - 점수 순위가 아니라 특징 이름으로 선택: `넓게 비운 개방형` / `구역 분리형` / `창가 워크스페이스형` / `수납 극대화형`.

## 4. 방봄(Bangbom) 3D 체험 요소 결합 (시간 여유 시 순차 적용)
`+6h` 핵심 통합(S1~S3)이 안정적으로 통과한 뒤, S4의 발표 임팩트를 극대화하기 위해 아래 순서로 붙인다.
1. **[1순위] 시간대별 채광 토글:** `[아침 08:00]` / `[낮 13:00]` / `[저녁 18:30]` 버튼으로 `DirectionalLight` 각도와 색온도를 바꿔 실제 채광 분위기 체험.
2. **[2순위] 1인칭 걷기(Walkthrough) & 눈높이 전환:**
   - `[조감]` ↔ `[1인칭 걷기(성인 160cm)]` ↔ `[아이 눈높이 90cm]` 전환.
   - PC는 `WASD` + 마우스 드래그, 모바일은 좌하단 가상 조이스틱. DB 가구 직사각형 경계로 벽·가구 통과 방지.
3. **[3순위] 고화질 3D 스냅샷 저장:** 현재 시점을 PNG로 내려받아 S3 단지 상세의 체크리스트와 함께 보관.
