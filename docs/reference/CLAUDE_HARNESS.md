# CLAUDE_HARNESS.md · 온라인 모델하우스 (v2) AI 코딩 작업 하네스

> 이 문서는 `PROJECT.md`, `API_SPEC.md`, `MODEL_SPEC.md`, `MAP_STYLE_GUIDE.md`, `TASKS.md`와 함께 프로젝트 루트(`CLAUDE.md`로 복사 가능)에 두고, VS Code 내 Claude Code가 일관되고 안전하게 작업하도록 통제하는 최상위 규칙입니다.
> 기존 5개 문서의 내용을 반복하지 않고, **AI 코딩 가드레일 · 스택 정합성 · 자동 검증 루프**만 정의합니다.

---

## 1. 언어 및 작업 보고 규칙
- 모든 답변, 코드 주석, 커밋 메시지, UI 문구는 **자연스러운 한국어**로 작성한다.
- 매 작업 끝에는 `PROJECT.md` 원칙에 따라 반드시 **① 실행 방법**과 **② 다음 할 일 3개**를 남긴다.
- "완료"라고 보고하기 전에 반드시 실제 테스트·빌드 명령을 실행해 통과 결과를 확인한다.

## 2. 문서 우선순위 및 충돌 해결 기준 (다듬기 반영)
기존 문서 사이에 일부 버전 차이가 있으므로 AI 도구는 아래 우선순위를 따른다.
1. **2.5D 지도 시각 스타일:** `MAP_STYLE_GUIDE.md`가 `MODEL_SPEC.md`(A장)와 `TASKS.md`의 "저녁 남색 지도" 설명을 **완전히 대체**한다. (무광 흰 점토 클레이 `#EEF0EE` 톤 고정)
2. **좌표 및 데이터 필드:** `API_SPEC.md`와 `MODEL_SPEC.md`의 좌표(`map_x`, `map_z`, `x/z/rotation_y`)를 따른다.
3. **서비스 명칭 통일:** UI·리포트·고지 문구의 서비스명은 `기획안.md` 일부에 남은 "방봄" 대신 **`온라인 모델하우스`**(또는 PM이 확정한 최종 서비스명)로 통일한다.
4. **작업 폴더 격리:** 역할별 담당 영역(`frontend/src/map/`, `frontend/src/room/`, `backend/`) 밖의 파일은 명시적 요청 없이 수정하지 않는다.

## 3. 절대 불변 가드레일 (Guardrails — 위반 금지)
1. **계산은 코드, 설명·추정은 AI:**
   - 대출·정책 요건 판정(`eligible` / `needs_check` / `ineligible`), 실부담 월액, 인프라 거리(하버사인), S4 가구 좌표·겹침·통로·예산 합계는 **100% 결정론적 코드(Python/TS)**로 계산한다.
   - LLM/AI에게 금액·좌표·점수를 계산시키지 않는다.
2. **판정 표현 엄수:**
   - UI와 API 응답 어디에도 `"대출 가능"` / `"대출 불가"`처럼 은행 승인을 단정하는 표현을 쓰지 않는다.
   - 반드시 **`요건 충족` / `확인 필요` / `미충족`** 3단계만 사용한다.
3. **S4 가구 배치 점수제 금지:**
   - 100점 만점 점수제를 넣지 않는다. **`확실한 문제(오류)` / `개선 제안(관습 팁)` / `취향별 테마 배치안`** 3단계 피드백으로만 제공한다.
4. **API 키 및 비밀값 격리:**
   - 모든 외부 API 키는 `backend/.env` 서버 환경변수에서만 읽는다.
   - `frontend/` 코드나 `VITE_*` 환경변수, Git 커밋에 키나 개인 경로를 절대 포함하지 않는다.
5. **무단 크롤링 금지:**
   - 부동산 앱(직방 등), 쇼핑몰(오늘의집·다나와 등) 페이지를 백엔드에서 자동 스크래핑하지 않는다.
   - 가구 구매는 공식 검색 링크 연결 + 사용자 직접 입력 방식으로 처리한다.
6. **정직한 고지 문구 고정:**
   - 지도/상세 하단: `"샘플 데이터 · 참고용, 최종 판정과 승인은 각 기관"`
   - S4 예상 가격: `"시연용 예상 가격"`, 통로 60cm 기준: `"참고값"`
7. **시연 무중단 (오프라인 & 목업 Fallback):**
   - 프론트엔드는 `VITE_USE_MOCK=true` 전환 시 백엔드 없이도 S1→S2→S3→S4 전체 시연이 가능해야 한다.
   - AI 호출 실패·지연(15초 초과) 시 규칙 기반 기본 문장으로 즉시 대체한다.

## 4. 완료 전 자동 검증 체크리스트
### Frontend (`frontend/`)
- `npm run build` (TypeScript 타입 오류 + Vite 번들 오류 0건)
- `VITE_USE_MOCK=true` 및 실제 백엔드 연동 양쪽에서 콘솔 에러 0건
- 2.5D 지도 40fps 이상 유지 (느려질 경우 `MAP_STYLE_GUIDE.md` 11장 순서대로 N8AO halfRes → shadow mapSize 1024 순으로 경량화)

### Backend (`backend/`)
- `pytest` (또는 페르소나 테스트 스크립트) 통과: 김지훈 페르소나 기준 `on` / `dim` / `off` 3단계 불빛이 모두 정상 분포하는지 확인
- `/api/match`의 `best~worst` 월 실부담 합계가 `/api/complexes/{id}/detail`의 `breakdown` 합계와 1원 오차 없이 일치하는지 검증
