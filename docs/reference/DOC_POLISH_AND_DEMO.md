## 2. 심사위원 3분 임팩트 시연 시나리오 (1등 공략)

`기획안.md`의 페르소나(김지훈, 27세, 월 실수령 250만 원, 자산 1,000만 원)를 그대로 살리되, **시각적 임팩트 → 숫자 신뢰성 → 입주 후 생활 연결** 순서로 3분을 꽉 채웁니다.

1. **[0:00~0:30] 훅(Hook) & 현장 QR 체험**
   - "대구 준공 후 미분양 3,077호. 빈집은 넘치는데 대구로 취업 온 청년은 내가 들어갈 수 있는 집조차 모릅니다."
   - 슬라이드 우측에 **공개 웹 URL QR코드**(및 Android `.apk` 링크)를 띄워 심사위원이 손안에서 함께 열도록 유도.
2. **[0:30~1:15] S1 → S2 (불이 켜지는 2.5D 클레이 대구 지도)**
   - 김지훈 조건 30초 입력 → **무광 흰 점토 대구 지도 위에 입주 가능한 미분양 단지 3곳에만 따뜻한 노랑 불빛(`on`)이 켜지고, 조건부 2곳은 깜빡임(`dim`), 불가 3곳은 꺼짐(`off`)**이 한눈에 펼쳐지는 순간이 첫 번째 하이라이트.
   - `off` 단지 1곳을 클릭해 "왜 못 들어가는지" 이유를 보여주고, `on` 단지(예: 상인푸르지오 센터파크)를 클릭 → **지하철·병원·쇼핑몰로 곡선 점선이 0.5초 만에 뻗어 나가며 "상인역 · 도보 6분" 라벨과 "지원 반영 월 26만 원" 카드** 표시.
3. **[1:15~2:00] S3 (믿을 수 있는 판정 구조)**
   - 상세 화면 진입: `"대출 가능"` 대신 **`요건 충족 / 확인 필요 / 미충족`** 3단계 표시와 `지원 다 받으면 ~ 못 받으면` 범위 강조.
   - **"계약금 전 은행 사전 상담 / 대출 불가 시 계약 해제 특약"** 체크리스트를 짚어, 단순 검색 앱이 아니라 청년의 계약금 손실을 막는 안전장치임을 어필.
4. **[2:00~2:35] S4 → S5 (3D 평형 가구 배치 — 30초 임팩트)**
   - S3에서 **[이 집에 가구 놓아보기]** 클릭 → 해당 평형(`room_84a` 등)에 예산 내 추천 가구가 배치된 3D 화면 오픈.
   - 가구를 하나 옮겨 실시간 오류/개선 팁 확인 + 보유 가구(`[이미 있어요]`) 제외 시 S5 구매 총액이 즉시 줄어드는 모습만 **30초 내로 깔끔하게** 보여줌.
5. **[2:35~3:00] 마무리 (실현 가능성 & 웹·앱 확장)**
   - React+TS+R3F+FastAPI 및 Capacitor 단일 코드베이스로 **웹과 모바일 앱을 동시에 구현**한 완성도와, 대구시·CR리츠·LH 연계 운영 모델을 강조하며 마무리.

## 3. 예상 심사위원 Q&A 방어 스크립트 (핵심 4선)
- **Q1. "실제 은행 대출 심사랑 다르면 사용자가 피해 보지 않나요?"**
  - A. "그래서 서비스 어디에도 '대출 가능'이라고 단정하지 않습니다. `요건 충족 / 확인 필요 / 미충족` 3단계와 '지원 못 받을 때의 최대 부담액'을 함께 보여주고, 체크리스트 최상단에 '계약금 전 은행 사전 상담 및 대출 불가 해제 특약'을 배치해 손실을 예방하도록 설계했습니다."
- **Q2. "대구 미분양 단지 데이터는 실제 데이터인가요?"**
  - A. "국토부 2026년 9월 통계(준공 후 미분양 3,077호)와 CR리츠·LH 든든전세 등 공개된 실제 단지 3~5곳을 반영했고, 비공개 세부 항목은 `(샘플)` 표기와 하단 고지 문구로 투명하게 구분했습니다. 실서비스 단계에서는 대구시·공급자 제휴 API로 교체할 수 있도록 데이터 파일(`complexes.json`, `rules.json`)을 코드와 완전히 분리했습니다."
- **Q3. "2.5D 지도에 3D 가구 배치까지 넣으면 주제가 분산되지 않나요?"**
  - A. "S4는 꾸미기가 아니라 **'내 예산으로 이 평형에 실제로 들어가 살 수 있는지'**를 최종 확인하는 입주 판단 단계입니다. S3에서 평형 ID와 남은 예산이 그대로 이어지고, 시연에서도 핵심(S1~S3)을 중심에 두되 S4는 30초 내 의사결정 보조로만 배치했습니다."
- **Q4. "모바일에서도 무겁지 않고 잘 돌아가나요?"**
  - A. "외부 무거운 3D 모델 없이 코드 기반 `instancedMesh`와 경량 클레이 셰이더를 사용해 40fps 이상을 확보했고, 프레임이 떨어지면 후처리(N8AO·그림자)를 단계적으로 낮추는 안전장치까지 넣었습니다. Capacitor로 웹과 모바일 앱을 단일 코드로 빌드했습니다."
