# 작업지시서 3 · 실부담 계산 검증

**목표**: 앱이 보여 주는 "지원 반영 후 한 달 실부담"이 맞는지 검증하고, **"일반 전세에 살 때보다 한 달에 얼마 덜 낸다"** 비교를 만든다. 이게 다른 앱에 없는 숫자다.

## 지금 앱의 계산식
- 필요 대출 = 보증금 − 모은 돈
- 월 이자 = 필요 대출 × 금리 ÷ 12  (버팀목 2.5%, 시중 4.5%, 대구 이자지원은 금리에서 차감)
- **월 실부담 = 월세 + 관리비 + 월 이자 − 월세지원**
- 범위: "지원 모두 받으면 ~ / 하나도 못 받으면(시중금리) ~"

## 할 일
1. **계산식 점검**: 빠진 비용이 없는지 확인하고, 넣을지 말지 의견 달기
   - 전세보증보험료(연 보증료 ÷ 12), 중개수수료(1회성 → 24개월로 나눔?), 이사비
   - 버팀목의 **보증금 대비 대출 비율(80%)** — 넣으면 자기자금이 얼마 필요한지
   - 정책 중복 불가 조합 (작업지시서 2 결과와 맞추기)
2. **손 계산 테스트**: 아래 3명 × 단지 3곳을 엑셀(또는 계산기)로 직접 계산 → 앱 결과와 비교
   - A 김지훈: 27세, 월 실수령 250만, 모은 돈 1,000만, 무주택, 대구 전입 예정, 예산 60만
   - B: 33세, 월 실수령 320만, 모은 돈 4,000만, 예산 80만
   - C: 38세(대구 이자지원은 되고 버팀목은 안 되는 나이), 월 실수령 280만, 모은 돈 2,000만, 예산 70만
3. **일반 전세와 비교**: 작업지시서 1의 "주변 전세 시세"로 같은 사람이 일반 전세에 살 때 월 부담을 계산
   - "방봄 단지: 월 44만 / 같은 동 일반 전세: 월 61만 → 월 17만 원, 2년 408만 원 절약" 형식
