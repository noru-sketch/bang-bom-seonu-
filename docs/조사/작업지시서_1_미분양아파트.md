# 작업지시서 1 · 미분양 아파트 (임대 전환 단지)

**목표**: 지금 앱의 단지 8곳 중 7곳이 샘플이다. **실제 대구 미분양 임대 전환 단지를 최대한 많이(목표 5곳 이상)** 찾아서 샘플을 바꾸고, "주변보다 싸고 좋다"를 숫자로 보여 준다.

## 찾을 것
1. **CR리츠(기업구조조정 리츠)가 매입해 전세·임대로 내놓은 대구 단지** (상인푸르지오 센터파크 외)
2. **LH가 매입한 대구 준공 후 미분양 → 든든전세·매입임대로 공급된 단지**
3. 건설사가 직접 **임대(전세) 전환**하거나 할인 분양 중인 대구 단지 (참고용)
4. 각 단지의 **주변 시세**: 같은 동·비슷한 평형 아파트의 최근 전세 실거래가 → "시세 대비 몇 % 낮은지"
5. **안전성 근거**: 임대인(LH/리츠/건설사), 전세보증보험 가입 가능 여부, 선순위 대출 여부(공고에 나온 만큼)

## 어디서
- LH청약플러스(apply.lh.or.kr) 든든전세·매입임대 공고, 마이홈포털(myhome.go.kr)
- 국토부·LH 보도자료 ("지방 준공 후 미분양 매입", "CR리츠")
- 뉴스: 대구 지역지(매일신문, 영남일보, 대구일보, 경북매일) + 뉴시스·뉴스1 "대구 CR리츠 전세"
- 주변 시세: **국토교통부 실거래가 공개시스템(rt.molit.go.kr)** 아파트 전월세
