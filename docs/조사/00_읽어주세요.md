## 공통 규칙
1. **숫자에는 반드시 출처 URL과 확인 날짜**를 붙인다. 출처 없는 숫자는 발표·화면에 못 쓴다.
2. 뉴스보다 **원문(공고문, 공공기관 보도자료, 통계 원자료)** 을 우선한다. 뉴스만 있으면 "보도 기준"이라고 적는다.
3. 확인 못 한 것은 비워 두고 "확인 필요"라고 쓴다. 추측해서 채우지 않는다.
4. "대출 가능", "안전 보장", "확정" 같은 단정 표현은 쓰지 않는다.
5. AI(ChatGPT·Claude 등)로 찾은 내용은 **원문을 직접 열어서 확인한 것만** 적는다.
