# 결과 1 · 대구 미분양 아파트 (전세·월세·매매) — 1차 조사 + 검증
작성: Claude(선우 요청) · 2026-11-26 22시 · 담당자가 이어서 보완

## 한눈에 보는 결론
1. **샘플을 실제 단지로 바꿀 수 있다.** 미분양 → 임대 전환이 확인된 대구 단지 5곳(전세 4 · 월세 1)과 할인분양 사례 1건을 찾았다.
2. **"725가구 vs 990가구" 불일치가 풀렸다.** 2025년 12월 기준 4개 단지 725가구 + 상인푸르지오 990가구 = **1,715가구**이고, 이는 LH 관계자가 말한 "대구 CR리츠 매각 1,715가구(2026년 2월)"와 정확히 맞는다.
3. **"더 싸다"는 근거가 있다.** 상인푸르지오 전세는 인근 아파트 시세보다 **최대 1억 원가량 저렴**하다는 보도가 있다(뉴스1). 할인분양은 7억 3,900만 원 → 5억 7,900만 원(약 22%) 사례가 있다(대구MBC, 단지명 비공개).
4. **"안전하다"는 단지마다 확인해야 한다.** 상인푸르지오는 HUG 보증이 보도로 확인되지만, 다른 임대 전환 단지(대명더퍼스트)는 "보증보험이 안 된다"는 상담 글과 "가입 가능"이라는 광고가 엇갈린다. → 앱에 **"보증보험 가입 가능 여부: 확인됨/미확인"** 칸이 필요하다.
5. **앱 좌표 수정 필요**: 상인푸르지오 실제 주소(상화로 245)는 앱 좌표보다 약 1km 남쪽이다.

## 3. 앱에 넣는 방법 (제안)
- **샘플 교체**: c01 상인푸르지오(좌표 수정), c03 → 힐스테이트 대구역 퍼스트, c05 → 수성레이크 우방아이유쉘, c06 → 빌리브 라디체, c07 → 힐스테이트 칠성 더 오페라(월세). 가격이 확인 안 된 단지는 **"가격 미확인 · 문의"**로 두고 판정 대신 "가격 확인 후 판정" 표시. 나머지 샘플은 "(샘플)" 유지.
- **"왜 이 집?" 예시**
  - 상인푸르지오: "2024년 준공 신축 · 임대인 CR리츠 · HUG 보증 · 인근 시세보다 최대 1억 원 저렴(보도)"
  - 대구역 퍼스트: "2025년 준공 · 대구역 도보권 · 분양가 5~6억 원대 단지를 리츠 임대로"
- **카드에 안전 칸 추가**: 임대인 유형(공공/리츠/시행사/개인), HUG 보증 확인 여부(확인됨/미확인), 신탁 등기 여부 → "확인 필요" 항목은 체크리스트로 연결.

## 4. 3번(실부담)에 주는 영향
- 상인푸르지오가 인근 시세보다 **1억 원 싸다면**, 같은 사람이 인근 일반 전세에 살 때보다 대출이 1억 원 줄어 **시중금리 4.5% 기준 월 약 37.5만 원 · 2년 약 900만 원**을 덜 낸다. (결과 3에서 가정한 "10% 저렴"보다 큰 효과 → "최대" 표현이므로 발표에서는 "최대"를 꼭 붙인다.)
- 매매 비교에는 대구MBC 할인 사례(약 22%)나 대구역 퍼스트(분양가 5~6억 → 실거래 4.9억)를 쓸 수 있다.
