# 방봄 BANGBOM · 온라인 모델하우스

대구 미분양 아파트를 지도에서 찾아보고, 내 조건으로 판정해 보고, 집 안을 3D로 둘러보는 웹사이트예요.
전국 바이브톤 경진대회 출품작 (팀장 선우 · 백엔드 경동휘 · 프론트엔드 혜원)

## 바로 열어보기
1. 압축을 풀어요.
2. `index.html`을 크롬으로 열면 돼요. (3D 지도에 쓰는 three.js를 인터넷에서 불러와서 인터넷 연결은 필요해요)
3. 온라인 링크: https://claude.ai/artifact/Dr7q9c9r5fbLqXRyW1AKCF

## 화면 흐름
홈 → 정보 입력 → 판정 결과 → 대구 미분양 지도 → 단지 카드 → 집 보기(평면도·조감도·방 안, 가구 배치, 예산, 구매 목록) → 24시간 상담

주소 끝을 `#home` `#input` `#map` `#house` `#guide`로 바꾸면 해당 화면으로 바로 갈 수 있어요.

## 폴더 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 완성본 (한 파일에 HTML·CSS·JS 모두 포함) |
| `img/` `vid/` | 홈 화면 이미지와 영상 |
| `fonts/` | Pretendard 폰트 |
| `CLAUDE.md` | 프로젝트 규칙 (데이터 출처, 판정 문구 등) |
| `src/home/` | 방봄 홈 화면 HTML 원본 |
| `src/modelhouse/` | 지도·집 보기 원본 (`data.js` 단지 데이터, `data2.js` 인프라·가구, `engine.js` 판정 규칙, `house.js` 평면 구조) |
| `src/modelhouse/geo.js` | 대구 9개 구·군 경계와 강·도로·산 위치 (지도 바닥) |
| `src/shell/` | 화면 전환(`shell.js`), 지도·집 보기 화면(`app_bb.js`), 합치는 스크립트(`build.py`) |
| `src/tools/make_geo.py` | 행정경계 원본에서 `geo.js`를 만드는 스크립트 |

## 수정하는 법
`src/` 안 파일을 고친 다음 아래 명령을 실행하면 `index.html`이 다시 만들어져요. (Python 3 필요)

```
python3 src/shell/build.py
```

데이터만 바꿀 때는 `src/modelhouse/data.js`, `data2.js`만 고치면 돼요. 백엔드 서버 없이 브라우저에서만 돌아가요.

## 지도
- 바닥은 대구 9개 구·군(군위군 포함) 실제 경계 모양이에요. 출처: 통계청·행정안전부 행정동 경계(2023.7 기준, vuski/admdongkor 정리본)를 구·군 단위로 합쳐서 단순화했어요.
- 강(금호강·신천), 큰 도로, 산 위치는 실제 위치를 참고해 대략 그린 **예시**예요. 주변 건물 블록도 예시고, 실제 건물이 아니에요.
- 내 조건을 넣으면 지도가 저녁 톤으로 바뀌어요. 조건이 맞는 단지는 불이 켜지고 빛기둥이 올라가요. 일부만 맞는 단지는 깜빡이고, 안 맞는 단지는 회색으로 꺼져요.

## 아직 남은 것
- `img/story.jpg` (팀 사진)는 아직 없어요. 파일이 생기면 같은 이름으로 `img/`에 넣으면 바로 적용돼요.
- 단지 카드 위에 검은 띠가 보이는 문제는 아직 확인 못 했어요.

## 주의
- 모든 단지·가격 데이터는 **샘플 데이터 · 참고용**이에요. 최종 판정과 승인은 각 기관에서 해요.
- 판정 문구는 "요건 충족 / 확인 필요 / 미충족"만 써요. "대출 가능", "입주 가능" 같은 말은 쓰지 않아요.
